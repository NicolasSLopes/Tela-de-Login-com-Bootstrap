# Tela-de-Login-com-Bootstrap

## Sobre o Projeto

Este projeto consiste no desenvolvimento de uma tela de login responsiva e moderna utilizando o framework Bootstrap. O objetivo principal foi explorar e aplicar os componentes pré-estilizados e o sistema de grids do Bootstrap para acelerar o desenvolvimento de interfaces web sem abrir mão da qualidade visual.

A interface foi estruturada no arquivo `index.html` e conta com comportamentos interativos dinâmicos (como validação de campos ou manipulação de eventos) gerenciados por scripts no arquivo JavaScript do projeto.

---

## Funcionalidades

* Layout de login moderno, limpo e totalmente responsivo (adaptável a celulares, tablets e desktops).
* Utilização de componentes do Bootstrap (cards, inputs, botões, espaçamentos e utilitários).
* Estruturação ágil utilizando a folha de estilos do framework.
* Validação de formulário ou comportamento interativo implementado com JavaScript.
* Alinhamento e centralização perfeita dos elementos na tela através do sistema de Grid/Flexbox do Bootstrap.

---

## Tecnologias Utilizadas

* **HTML5**
* **Bootstrap (CSS Framework)**
* **JavaScript (ES6+)**

---

## Objetivo

O principal objetivo deste projeto é praticar a integração e o uso do Bootstrap em projetos práticos de front-end, compreendendo como suas classes utilitárias e componentes facilitam a criação de layouts responsivos e padronizados.

---

## Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados conceitos como:

* Configuração e inclusão do Bootstrap via CDN ou arquivos locais.
* Uso do sistema de grid e utilitários de flexbox do Bootstrap para posicionamento.
* Estilização de componentes de formulário nativos do framework.
* Manipulação do estado do formulário e eventos de clique através do JavaScript.
* Criação de interfaces focadas em Mobile-First e responsividade.
